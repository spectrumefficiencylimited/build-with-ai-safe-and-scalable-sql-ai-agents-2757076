However, it loses the implicit constraints from the previous question, such as the year and activity type. This highlights a key limitation of stateless models. In this lesson, we learn how to add short-term memory to our SQL AI agent so users can ask natural follow-up questions without restating all the context. At the eye level, adding memory to an agent means injecting previous user questions and the corresponding LLM response into the prompt. This provides the model with conversational context and enables it to connect new questions with earlier ones. There are two important things to keep in mind when working with conversational memory. First, prompt size grows as conversation continues, increasing token usage. And older conversations may become irrelevant and can potentially mislead the model rather than help it. To address those issues, common strategies include using a sliding window to keep only the most recent interactions and applying summarization to compress older context. In the SQL agent model, in the course folder, we use a simple helper function called TreeMemory to remove all the conversations and keep the memory manageable.
